# v2.3.2-security-preview 追加停止検査

**会社データ投入・業務提出は禁止**。v2.3.1のコードを出発点に、会社報告書生成ルートを検査する合成データ専用版。

## 変更

- `transform_package()` が出力を作る前と後に `check_company_report_package()` を呼び、コメント、customXml、custom props、外部リンク参照、追加シート、追加写真/EMF、隠しシート、記入例シート、埋込オブジェクトがある場合は停止する。元データを削除・上書き・リンク解除しない。
- `calcPr`がない場合、後続要素の前に挿入し、再計算を要求する。
- テストコードは自己完結した架空のOOXMLで作られる。

## 特に注意

この検査は対象ファイル内にありうるすべての情報漏えい経路を特定する万能のDLPではない。たとえばシート1とシート2の未指定セル、図形テキスト、数式文字列などは依然として完全に網羅できない。

**既存の正当な外部リンク・EMF・補助シートも停止の対象**。動くようにするためにリンクやEMFを無断削除してはいけない。施設側で承認された空白ひな形を作り、リンク更新設定・印刷設定・数式・図形を整理した上で、ハッシュ固定と部品単位の承認リストを作る必要がある。現行の会社様式ハッシュ値は旧版から引き継いでいるが、旧様式が安全に扱えることを意味しない。
