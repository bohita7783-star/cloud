Field Survey → 会社Excel 写真帳変換ツール v2.5.0-layout-preview（件名ファイル名対応・検証版）
============================================================
重要：Field Surveyアプリそのものを改造したものではありません。
      Field Surveyが最初に書き出すXLSX/ZIPの元ファイル名は変更できません。
      このツールで「案件を選んで変換」したあと、件名付きの案件別コピーを生成します。
      元XLSX・元ZIP・会社Excel原本の3ファイルはいずれも変更・削除しません。
      未検証の会社提出書類として使わず、必ず元データ・画像・印刷結果を確認してください。

【追加したファイル名自動生成】
案件件名が「共用通路天井漏水あり」で出力日時が202611041850の場合
1. 共用通路天井漏水あり_FieldSurvey_ab12cd34_202611041850.xlsx
   → この案件1件とその対応経過・写真行だけに絞ったField Survey元データのコピー
2. 共用通路天井漏水あり_FieldSurvey_ab12cd34_photos_202611041850.zip
   → この案件の元写真だけを詰めたZIPコピー
3. 共用通路天井漏水あり_会社書式_要確認_202611041850_ab12cd34.xlsx
   → 選択・修正した写真と説明を会社Excelの枠へ配置した検証用ファイル
4. 同じ3番のファイル名の .json → 実行監査ログ

ファイル名には案件件名を使います。ファイル名として使えない文字は除去し、
長すぎる件名は短縮し、重複を防ぐ8桁のランダム英数字を付けます。
原本のField Surveyの複数案件エクスポートは残したまま、選択案件のみ分離します。
【重要】ブラウザ画面で「写真を差し替える」「説明文を編集する」操作は3番の
会社書式Excelにのみ反映されます。1番・2番は変更前の元データコピーです。

【Pixel 9a / Termuxへの導入】
前提：Termux、Python、python-lxml、python-pillow、unzip、
      termux-setup-storageの初期設定は済んでいる。

1. ZIPをPixel 9aのDownloadへダウンロード。
2. Termuxに以下のコマンドを一行ずつ入力：
   cd ~
   unzip -o ~/storage/downloads/field_survey_converter_v2_6_0_layout_preview.zip
   # 旧社内ひな形をコピーしないでください（このプレビューでは実会社資料を使用禁止）
   ※架空のテスト用ひな形だけを使ってください。
   ※事前に会社が許可した社内Excelファイルだけを使用する。
3. 実行：
   bash ~/FS_Phone_Converter_v2_6_0/run_ui.sh
   ブラウザが開く（開かない時はTermuxに表示された http://127.0.0.1:... へ）。
   XLSX＋元写真ZIPを選択→件名で案件選択→写真を確認→変換。
4. 完成品の保存先：Androidの Download / FS_変換結果

【文字だけで実行したい場合】
   bash ~/FS_Phone_Converter_v2_6_0/run.sh
   まずExcel＋写真ZIPを選択、次に案件の件名を見ながら番号選択。
   終了後に案件別元データと会社書式Excelが同じフォルダーへ保存される。

・元ファイル上書き禁止、同一画像の二重挿入検出

【制約と未検証事項】
・Field Surveyアプリ標準のエクスポートボタンと、アプリ内部のファイル名は変わらない。
・会社書式は2026年10月17日の特定の原本だけ。対応写真は最大3枚。
・写真入り会社書式Excelは検証用であり正式提出用ではない。
・PixelのAndroid実機上でv2.5.0-layout-previewが動作したかは、ユーザー側で追加確認が必要。
・PC版Excelでの印刷・改ページ・図形表示は引き続き目視検証が必要。
・案件別元Excel/ZIPは元データのコピーで、ブラウザ編集後の内容は反映しない。
・元写真ZIPに写真が欠けている場合、会社Excel生成に成功しても案件別コピーが生成できない場合がある。
・他アプリの非公開領域はTermuxから読み取れない。
