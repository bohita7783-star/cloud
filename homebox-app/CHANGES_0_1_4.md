# HomeBox v0.1.4 — 正式17項目の固定（2026-11-07）

v0.1.3（台帳項目の追加・編集・非表示）をそのまま土台にし、**正式17項目だけは端末で変えられない**ようにした。

## なぜ

- 依頼は「17項目**以外**の項目を自由に追加・削除できるように」だった。v0.1.3 では正式17項目も、各スマホで非表示・改名・並べ替え・分類変更ができた。
- 台帳の正本は会社の台帳。端末ごとに17項目の名前・並び・有無が変わると、台帳CSVで会社台帳に戻すときに列が合わなくなる。

## 変更

- 正式17項目は、非表示・名前変更・単位変更・分類変更・並べ替えができない（設定画面で「正式・固定」と表示し、操作ボタンを出さない）。
- 新しい項目は必ず「追加項目」に入る（追加・編集の画面から分類の選択を外した）。
- 検査（`validateFieldSchema`）で、上の規則に反する定義を拒否する。項目設定JSONの取り込み、バックアップからの復元にも同じ規則を適用する。
- **v0.1.3 からの移行：** 起動時に、正式17項目への変更（非表示・改名・並べ替え）を会社の台帳どおりに戻す。追加項目は「追加項目」に移す。入力済みの値はそのまま。改名されていた名前はCSV取り込み用の別名として残す。変更履歴に `migrate:official17-fixed` を残す。
- 追加項目の追加・名前変更・並べ替え・非表示・復元、項目設定JSON、旧名でのCSV取り込みは v0.1.3 のまま。

## 検証

- `tests/test_dynamic_schema.js`：9件合格（正式17項目の固定と、v0.1.3 の変更を戻す処理を追加）
