# HomeBox 0.4.0 — 様式の版を確かめ、空様式に写真を貼る

変換エンジン 2.6.0-form-profile を同梱（詳細は converter/FS_Phone_Converter_v2_6_0/更新履歴_v2_6_0.txt）。

## 何が変わるか
- **空様式が使える**：写真を消した会社様式（空様式）を承認・登録すれば、写真は写真枠の上に貼られる（縦横比を保って枠に収める）。
- **様式の版を確かめる**：報告書シートの書き込み先96か所の枠と、写真シートの写真枠を、登録したファイルから読み取って照合する。配置が違う版・セル内画像や前の写真・赤丸が残った様式は、理由を出して止める。
- **10-31 の様式の3枚目の説明欄**（N48/N51…）に正しく入る（0.3.0 までは 10-17 の位置で決め打ち）。
- 写真の説明は、撮影場所＋説明の各行＋注釈を上から5行まで。超えると出力前に知らせる。
- 設定と案件画面に、登録した様式の種類・写真枠の数・写真の入れ方・承認者を表示（テスト用の様式を会社様式と取り違えないため）。

## 注意
- 承認済み一覧は**再署名が必要**（engine-2.6.0）。0.3.0 で登録した様式は「要再登録」と表示される。
- 写真は「図」として貼る（セル内画像ではない）。Excel 365 以外やスマホのビューアでも見え、赤丸を上に描ける。
- 赤丸・矢印などの書き込みは、今も Excel での手作業。

## テスト
- e2e_report_layout（空様式で登録→表示→Excel作成）、e2e_excel（旧方式）、e2e_app、e2e_schema を Chromium で合格。架空データのみ。
