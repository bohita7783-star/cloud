# ホームボックス v0.1（アプリ本体）

設備台帳（17項目）・写真・点検記録・異常案件を設備ごとに管理し、会社様式の報告書用パッケージを書き出すオフラインアプリ（PWA）。

- データはこの端末のブラウザの中だけ。外部へ通信しない。
- デザインは `homebox-lp/`（LP v0.1.1）を基準にしている。
- 全体構成は [ARCHITECTURE.md](ARCHITECTURE.md)、変換ツールとの受け渡し形式は [DATA_CONTRACT.md](DATA_CONTRACT.md)。

## Pixel で使う

1. このフォルダーを HTTPS で配信する（例：GitHub Pages で `…/homebox-app/`）。
2. Pixel の Chrome で開き、メニュー →「ホーム画面に追加」。
3. 設定 →「消されにくい設定」を有効にする。
4. 設定 →「空のCSVひな形」で台帳の形を確認し、会社台帳を CSV で取り込む（取り込んだ値は「未確認」）。
5. 「撮る」で設備を選んで撮影 → 異常案件で写真を選び、説明を書いて「報告書パッケージを書き出す」。
6. Termux で `bash ~/FS_Phone_Converter_v2_4_1/run_homebox.sh` → `Download/FS_変換結果` に会社様式の Excel。

## できること（v0.1）

| 画面 | 内容 |
|---|---|
| ホーム | 設備の横断検索、最近の写真、対応中の案件 |
| 設備台帳 | 分類・場所でまとめた一覧、17項目の値＋確認状況（確認済／未確認／対象外）＋出典、写真、点検記録、関連案件 |
| 撮る | 設備を選ぶ → 種別を選ぶ → 撮影。原本のまま保存し、`案件ID_設備ID_連番_種別.jpg` の規則で命名 |
| 異常案件 | Field Survey と同じ項目、写真3枚の選択と説明、対応経過8件、書き出し前の検査 |
| 設定 | バックアップ／復元（写真ごと）、台帳CSVの書き出し・取り込み（UTF-8・Shift_JIS）、全削除 |

## テスト

`tests/e2e_app.js` は、架空データでアプリを Chromium で一周操作する（CSV取り込み → 台帳 → 点検 → 撮影 → 案件 → 書き出し → バックアップ → 全削除 → 復元）。

```
python3 -m http.server 8765 --bind 127.0.0.1   # リポジトリのルートで
node homebox-app/tests/e2e_app.js http://127.0.0.1:8765/homebox-app/ <出力フォルダー> <架空のJPEG>
```

## 制限（v0.1）

- 17項目のうち7項目は仮（設定画面と台帳に「仮」と表示）。正式テンプレートで確定する。
- 写真は端末の容量を使う。定期的にバックアップを書き出すこと。
- 報告書は写真3枚・対応経過8件まで（現行様式の枠）。
- Pixel 9a の実機での動作確認はまだ。
