# HomeBox v0.1.3 — 台帳項目可変化（2026-11-07）

- v0.1.2の正式17項目と既存保存キーを維持して、台帳項目の定義をIndexedDBのmetaに保存する方式へ拡張。
- 設定画面で項目の追加、名称・単位・根拠の変更、基本／追加グループ変更、上下移動、非表示・復元を実装。
- 削除は保管（アーカイブ）とし、設備の入力値・確認状況・出典は消去しない。
- 変更前の項目名をCSV取込用別名として保持。CSVの未知列、非表示列、重複見出しの黙殺を防止。
- 項目設定だけをJSONとして配布／取込できる機能を追加。別端末の設備データには触れず、端末にのみ存在する項目は非表示で残す。
- 項目設定はスキーマ版・変更履歴（直近100件）付きで保存し、フルバックアップZIPに同梱。
- 既存のレポートパッケージは変更なし。変換ツールv2.4.2以降と互換の設計。
