# HomeBox 0.3.0 — 会社の報告書と同じ書き方で出力

変換エンジン 2.5.0-layout-preview を同梱。実際に提出されている現場異常速報を分析し、アプリで作る Excel を同じ書き方にした。

## 案件画面
- 欄の名前を様式に合わせた：「内容」「発見・通報者」「最初の状況（対応・処置内容の1行目）」「今後の予定・提案」「原因」「処置報告の内容」。
- 新しい欄：報告の段階（第１報〜最終・事故報告）、当事者と区分、連絡先、現場確認・一次対応の実施者と内容、処置報告の区分・実施者・確認者。
- 「通報・現状報告」：誰に何で伝えたか（区分・手段・相手・所属）。様式の枠数（オーナー・テナント4件など）を超えると出力前に知らせる。
- 「様式に入るか確認」：Excel と同じエンジンで、何行目に何が入るかを表示。入りきらない時は続報に分けるよう案内。
- 「続報を作る」：同じ内容をコピーして次の段階（第２報…）の案件を作る。

## 設定
- 報告者情報（部署・ビル名・氏名・役職）と「いつもの連絡先」。新しい案件に自動で入る。

## データ
- パッケージ形式 `hb-report-package/2`（/1 も変換可）。詳しくは DATA_CONTRACT.md。

## 注意
- エンジンの変更範囲が変わったため、承認済み一覧は管理者の再署名が必要（engine-2.5.0）。
- 承認するひな形は 2026-10-17／10-31 と同じ配置の空様式を使う。
