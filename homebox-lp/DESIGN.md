# ホームボックス LP — デザイン言語の翻訳メモ

参照元：お文具さん公式サイト・キャラクター画像（スクリーンショット4点）。
**画像・キャラクター・ロゴは一切流用しない。** 抽出するのは「造形のルール」だけで、
ホームボックス（設備管理アプリ）の題材にあわせて組み直す。

## 1. 参照元の分析（可愛さ以外の構成要素）

| 要素 | 観察した特徴 | 効いている理由 |
|---|---|---|
| 線 | 濃いこげ茶〜黒の**太い単線**。太さはほぼ一定、端と角は丸い。わずかに揺れる手描きの線 | 情報量を減らし、どんな背景でも輪郭で「物」として立つ |
| 形 | 角のないマシュマロ形。頭と胴が一体。腕は短い線1本、足は底辺の小さなコブ | 部品数が少ないので、縮小しても読める。丸＝安全・無害の印象 |
| 顔 | 点2つ＋小さな口。顔は上寄せで、**顔の周りの余白が広い** | 表情を作り込まない「無表情のおかしみ」 |
| 塗り | 影なし・グラデーションなしのベタ塗り。白／クリーム／オレンジ／紺／青灰 | 平面的でステッカーのよう。線と面だけで完結 |
| 配色 | 温かいクリームの地＋淡い黄色の大きな円。強い差し色は朱の判子とオレンジだけ。紺・青灰が冷色の重し | 暖色が主役、冷色は脇役。高彩度は1〜2点に絞る |
| 余白・構図 | 大きな円の上にキャラを1体だけ置く。判子が円の縁を**はみ出して**重なる | 一点主役。はみ出しで「貼った」感じが出る |
| 枠 | 太いオレンジの線で囲んだ角丸カード（半径大） | カード自体も線画のルールに従っている |
| 文字 | 極太の丸ゴシック見出し＋字間を広げた小さな英字（オレンジ）＋手書き風ローマ字 | 太さの落差で階層を作る。手書き英字が人肌を足す |
| 語り口 | 「プリンが好き」を3回くり返す箇条書き、「文房具とは関係ない」 | 淡々としたくり返しのユーモア。説明しすぎない |
| 群像 | 大小のキャラが重なり、頭の上に乗る | 大きさの差と重なりで仲の良さを見せる |
| 小物 | 魚の骨・プリンなどが傾いて散らばる | 傾きと散らばりでステッカー帳の楽しさ |
| UI | 丸いサムネイルに色リング、「ページのトップへ」もキャラ小物 | 機能部品にも世界観を通す |

## 2. ホームボックスへの翻訳ルール

| 参照元 | ホームボックスでの置き換え |
|---|---|
| 太い単線（--outline） | キャラも、ボタン・カード・入力欄の枠も同じ太さの線で描く。ボタンは線＋**ずらした硬い影**（影もベタ） |
| マシュマロ形のキャラ | 設備管理の道具そのものをキャラにする：箱（台帳）、カメラ、QR、メーター、図面、報告書。顔は点2つ＋弧の口（くちばしは使わない） |
| 黄色の大きな円 | ヒーローとキャラカードの背景円。1画面に1つだけ |
| 朱の判子「文」 | 設備点検の**「点検済」判子**。円の縁をはみ出させ、着地時にドンと押される |
| オレンジの枠 | 安全色のオレンジ（現場の注意色）として再解釈 |
| プリン・魚の骨 | ナット・スパナ・水滴・QR片のステッカー |
| 「プリンが好き」のくり返し | 各機能の箇条書きで、いちばん大事な1行を3回くり返す |
| 「文房具とは関係ない」 | 「家（ホーム）とは関係ない」 |
| 丸サムネイル | キャラ切り替えのタブ。カードの下辺に半分かかる |
| 「ページのトップへ」 | 箱キャラの小さな「うえへ」ボタン |

## 3. トークン

- 色：--paper（地）--surface（カード）--fg（文字）--stroke（UIの線）--outline（キャラの線）--sun（大円）--safety（オレンジ）--stamp（朱）--pipe（紺）--steel（青灰）--custard（クリーム）--sky（水色）--mint（確認済）
- 文字：見出し M PLUS Rounded 1c 800/900／本文 Zen Maru Gothic／手書き英字 Gochi Hand／ID・ファイル名 M PLUS 1 Code
- 線：UI 3px、キャラ 5（viewBox 120 基準）、角丸は大（カード 36px）と完全な円の2種類だけ
- ダークモード：地を夜の作業場の焦げ茶にし、キャラと大円はステッカーとして明るいまま残す

## 4. Webサイトとしての構成

1. ヘッダー：ロゴ（箱アイコン＋極太文字＋手書き英字）、ナビ、CTA「デモをためす」。スクロールで縮み、上端に進捗バー
2. ファーストビュー：見出し「設備のこと、ぜんぶ この箱に。」、大円＋箱キャラ＋点検済判子＋ステッカー、CTA 2つ
3. ティッカー：機能名が流れ続ける帯
4. なかまたち：機能をキャラカードで紹介（丸タブで切り替え）
5. しくみ：えらぶ→とる→だす（実際の順序なので番号を使う）＋操作できるデモ（設備を選んで撮影すると、命名規則どおりのファイル名と17項目台帳が出る）
6. みんなでひとつの台帳：重なり合う群像（パララックス）
7. ロードマップ＋よくある質問
8. 最終CTA、フッター、「うえへ」ボタン

## 5. 動き

| 種類 | 内容 |
|---|---|
| 読み込み | 見出しが1文字ずつ跳ねて着地 → 大円が膨らむ → 判子がドンと押される |
| 待機 | 箱キャラの呼吸（つぶれと伸び）とまばたき、ステッカーのゆれ、メーターの針、ティッカー |
| スクロール | 要素が少し下・傾き・縮小の状態から弾んで定位置へ（**透明にはしない**：止まった状態でも全部読める）、手順の点線が伸びる、群像のパララックス、ヘッダー縮小、進捗バー |
| ホバー | ボタンが影の分だけ沈む、カードが傾いて浮く、キャラがつぶれてジャンプ、タブが弾む |
| クリック | CTAから丸い紙吹雪、シャッターでフラッシュ＋写真が落ちてくる、タブ切り替えでカードが弾む |
| 配慮 | `prefers-reduced-motion` ではすべての動きを止める |
